## Состав

- Заточка мечей/копий/стрел +1…+3, один уголь за шаг. Оружие и стрелы хранят
  уровень отдельно по стопкам. Луки не точатся. Выбор сильнейшего доступного оружия.
- Мёртвые земли: один поход, три этажа, здоровье/стрелы/добыча между этажами;
  поверженные герои живы и ранены, не переходят дальше. Старые трупы не возрождаются.
- Видимость активных бойцов после ухода офлайн; поправки раненых и стартовых позиций.
- Голод для опыта по состоянию в начале цикла, еда по прежним правилам в конце.
- Вклады в задания; тёмные склады; обход воды; обводка здания по размеру спрайта.
- Меньше полной перерисовки после дел, обновление после возврата Telegram.
- Музыка деревни/боя, выключение и громкость на устройстве. Без загрузки аудио до
  взаимодействия. Мобильные правила autoplay и скрытая вкладка учитываются.
- Камыш уже бесконечен; регенерация не добавлялась.

## Найдено при проверке и исправлено

1. BestWeapon выбирал лук только по наличию стрел: мог создать несуществующий лук.
   Требуется доступный лук, тест сохраняет количество оружия.
2. buy-stock и legacy private-withdraw не знали про заточку и стирали её.
   Неулучшенный торговый инвентарь теперь принимает только обычные экземпляры;
   заточенные предметы доступны через выдачу со склада в ношу с сохранением +N.
   Заточка только в общественной кузнице: личная торговля пока не хранит +N.
3. Копия склада при проверке разбора теряла Sharpen, создавая одинаковые стопки.
4. Голод считывался в конце: ручная еда во время работы переписывала начало.
   Nullable CycleHungry фиксирует старт; старые оплаченные циклы используют fallback.
5. При смене этажа уже созданный спрайт шёл от координат предыдущей карты:
   его положение синхронизируется с новым входом.
6. Урон стрелы рассчитывался после её списания и мог потерять оружейный бонус.
   Сила удара фиксируется перед расходом стрелы.

## Данные и проверка

Три additive миграции: WeaponSharpen, ArrowSharpen (int default0), CycleStartHunger
(nullable bool). Старые JSON без Sharpen должны читаться как0. Новые поля старых
предметов не сбрасывают вещи, навыки, характеристики, ранения, оплаченные работы.
Обязательны real-PostgreSQL legacy migration/load/save и mixed-stack проверки,
полный Domain/API/browser CI, lint/build/Docker, тесты оператора. Успех и точные
SHA/CI будут записаны по факту, не до завершения.

Runtime auth и demo роли доступны только Development; Game:DevTools должен быть
выключен в production. Бюджет ИИ, режим Propose, реальные свечи/ключи и экономика
других игр не меняются. Изменение формата JSON исключает слепой downgrade.
