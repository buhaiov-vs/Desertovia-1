# Turnip sprites — draft batch

Three growth sprites and one harvested icon, generated separately using built-in image_gen with original Tiny Town and Tiny Farm style references. Exact prompts are in prompts.json. Original source PNGs, 16x16 full-canvas nearest-neighbor exports and 8x previews are preserved.

All four exports passed dimension checks and have transparent corners. Growth stages are visibly distinct at native size. Remaining audit: neon-green fringe is especially visible on the sprout, the palette has excess shading, and plant anchors/leaf proportions need consistency review against the farm beds. Ripe bulb is more exposed than intended. These remain drafts; no game integration performed.
