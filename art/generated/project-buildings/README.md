# Village project buildings — drafts

Great Granary (64x48) and Bell Tower (48x64), generated individually with built-in image_gen using original Kenney style references. Exact prompts in prompts.json. Source PNGs, native exports and 8x previews preserved. Exporter fits the visible alpha bounds proportionally inside a one-pixel margin using nearest-neighbor sampling.

Dimensions and transparent corners verified. Granary has two wide entrances, stone stilts and stored goods; tower has white masonry, open belfry, bell, onion dome and Orthodox cross. Both remain more detailed/shaded than the Kenney palette; edge artifacts remain, and tower perspective is too angled. Native-size silhouette, footprint and palette audit remain open. No game integration performed.
