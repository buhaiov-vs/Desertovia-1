# Stage construction drafts

Three separate transparent sprites: ground markers, raised plank floor, and back posts without pennants. Generated with built-in image_gen in edit mode; exact prompts and reference paths are in prompts.json.

Each source is preserved alongside a 48x48 full-canvas nearest-neighbor export and an 8x preview. No game integration performed.

Audit remains open: ground string has colored edge artifacts; platform depth, support arrangement and base position vary between floor and frame. Palette simplification and exact alignment with the finished building are required before final acceptance.
