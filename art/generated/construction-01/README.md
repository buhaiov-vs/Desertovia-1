# Construction stages 01

Five 32x32 construction stages: Heap ground, Lean-to frame and cover, Wood pile first logs, Stone pile ring. Built-in image_gen edit mode used the finished building previews as references. Exact prompts are in prompts.json.

Originals, full-canvas nearest-neighbor exports, and 8x previews are preserved. All exports were inspected; dimensions and transparent corner were verified. Do not treat these as production-aligned animation frames: structural drift, excess framing, and palette shading still require correction. The wood pile also retains its reference axe and stump.

The separate construction-catalog.json tracks all 62 requested stages. No game integration was performed.
