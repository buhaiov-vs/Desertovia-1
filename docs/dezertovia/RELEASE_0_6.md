# Дезертовия0.6 — кандидат

D-056/D-057,15.10.2026. Владелец разрешил реализовать и включить единого директора
с личными предложениями через батюшку и согласием/отказом. До подтверждения
точных SHA/CI/установки ниже это КАНДИДАТ, не описание уже работающего сервера.

## Что входит

Один Всевышний: общая память/замысел, наблюдения и прошлые решения сохраняются
в PostgreSQL. Он получает факты города, запасы/прошлый снимок, охрану/ранения/
погоду/стройку/износ, чат как недоверенные данные. Каталоги врагов, вещей,
вооружения и рецептов берутся из игры; варианты инструментов задаёт сервер.

Механизм включён в режиме Propose: анализ сам, эффекты после согласия царя.
Батюшка присылает в личку «Я вижу… предлагаю…» с последствиями и кнопками.
Есть дублирующая панель в «Городе»: память, предложения, режимы, журнал, время
следующего обзора и ошибки связи. Изменения условий, истёкший срок или Off
не позволяют старой кнопке запустить событие. Повтор согласия не повторяет эффект.
Неизвестная доставка Telegram не пересылается автоматически.

Показатели раз в минуту, обычный анализ15мин; важное изменение от5мин,
максимум4/час и96/сутки. Весь AI transport дополнительно ограничен общими
бюджетами бота. Одно новое предложение не чаще30мин, актуально30мин;
отклонённый/применённый тип не навязывается снова2ч. None — нормальное решение.

Опции: малая разрешённая волна, направленный подход для координируемых врагов,
передышка2ч, объявление о реальной стройке/ремонте, экономический совет,
добровольный сбор в существующий данж. Директор не подставляет аккаунт царя
при запуске; внутренний исполнитель применяет только разрешённое решение.
Ручные события сохраняются, передышка не отменяет объявленные волны.

Серверный тактический срез: маршруты обходят river/footprints/uncleared obstacles;
3 подхода, маршрут сохраняется вместе с волной. Охрана выбирает направление,
перестроение30реальных секунд. Против направленной атаки резерв Авто даёт75%
личного вклада, охрана своего сектора — полный, чужого — не участвует.
Для старых обычных нападений прежняя оборона сохранена. Несколько самостоятельных
отрядов, осадные стены/башни и новые способности врагов не объявлены готовыми.

Экономические советы по наблюдениям — не полный денежный ledger. Нельзя
объявлять остатки прибылью. Реальные свечи/курс/налог/кошельки автоматически
не меняются; принятие совета — запись, не скрытое списание. Новые торговые
сценарии/караваданы требуют отдельных правил, директор не выдумывает эмиссию.

В выпуск также входят подготовленные D-052/D-053: история по нажатию версии,
враги появляются после таймера, медицинские сроки с явной реальной шкалой.

## Сохранность и выпуск

Одна additive EF migration20261015152237_AlmightyDirector:3 таблицы состояния/
наблюдений/предложений, nullable поля охраны. Старые JSON-рейды получают только
недостающий пустой ApproachPath, их сроки/итоги не переписываются.
Без сброса профилей/навыков/XP/славы/ресурсов. Перед установкой свежие PostgreSQL
и SQLite backups и снимок для сравнения; не восстанавливать старую БД поверх
живого прогресса при откате кода.

Bot: только almighty.py, app.py, town_proxy.py поверх текущей канонической
основы. Приватный exact-source operator проверяет исходные hashes, CI,
proxy/auth/hospital и владельца. После установки Enabled/Propose и первый
настоящий анализ, без синтетических сообщений или платежей. Нужные личные
предложения — явно запрошенная владельцем функция.
