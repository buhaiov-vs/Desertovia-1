# Flax sprites — draft batch

Three growth stages and a harvested bundle generated separately using built-in image_gen, with original Kenney sheets as style references. Exact prompts are in prompts.json. Sources, 16x16 nearest-neighbor exports and enlarged previews are preserved.

All four exports passed dimensions and transparent-corner checks. Native-size review: blue flowers distinguish ripe flax and the bundle, but thin stems lose continuity and five-petal shapes do not survive downsampling. Sprout has severe bright green/white artifacts; young has bright edge pixels. Stem colors differ across stages, and harvested stems are too thick. Palette simplification, edge repair and planting-anchor alignment remain required. No game integration performed.
