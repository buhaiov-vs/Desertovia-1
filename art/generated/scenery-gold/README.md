# Gold vein scenery — drafts

Bare grey terrain, gold-bearing rock, and depleted rock. Built-in image_gen generated the first two with Tiny Town/Tiny Farm references, then edited the gold-bearing source to create the depleted state. Exact prompts in prompts.json. Sources, 16x16 full-canvas nearest-neighbor exports and 8x previews preserved.

Dimensions verified. Terrain top-left alpha is 255; rock corners are transparent. Gold and depleted exports have identical occupied pixels at alpha threshold 128. The source shows two glints, and the depleted source replaces gold with a dark hollow and pick marks. Native-size glints and pick marks lose definition; rocks occupy a small portion of the canvas. Limited palette, edge cleanup, sizing and terrain seams remain unapproved. No game integration.
