# Deer animation — draft

Three separately generated frames: standing and two trotting poses. Built-in image_gen with Tiny Town and Tiny Farm references; both moving frames also use the standing source as identity reference. Exact prompts in prompts.json. Original sources, 16x16 nearest-neighbor exports and 8x previews preserved. assemble.ps1 joins the frames in order into character-deer.png, a 48x16 strip without gaps.

Export dimensions and transparent corners pass. Native review: right-facing deer silhouettes and white markings remain visible, with distinguishable leg configurations. Small antler branches and eyes lose definition. The reference keeps upper-body proportions fairly consistent, but frame colors vary and independent bounds fitting does not guarantee animation alignment. Source shading exceeds the requested flat limited palette; loop motion and pixel cleanup remain unapproved. No game integration.
