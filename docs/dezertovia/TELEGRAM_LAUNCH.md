- Мир стартует по правилам автора с лагеря. Старый игровой прогресс не импортирован.
  Чат пока исходный; режимы скрытый/четверть/full остаются следующей задачей.

## Выпуск и возврат

Оператор хранится в изолированной ветке `ops/desertovia-launch` репозитория
`desertod666/bolig-agent`; ветка housing main не менялась. Диспетчеризация
`sramoslav.yml` всегда с `ref=ops/desertovia-launch` и тем же workflow ref.

1. `desertovia-deploy` +40-значный `desertovia_sha`: собрать выбранный проверенный коммит.
2. `desertovia-proxy-install`: только три проверенных файла бота, baseline guard и возврат при сбое.
3. `desertovia-switch`: снимок старой БД, proxy flag и restart бота.
4. `desertovia-check`: отдельные local/public health-проверки.
5. `desertovia-rollback`: убрать только proxy flag и restart; старые данные остаются,
   контейнеры/новая БД не уничтожаются. Для возврата к новой игре повторить switch.

Не использовать для этого полную старую ветку TG-bots0.4.3: там другие невыпущенные изменения.
Не размещать токен, server.env, БД, рабочие cookie или конфигурацию соединения в GitHub.
