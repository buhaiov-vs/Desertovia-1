# Storehouse construction stages

Five 64x48 construction drafts generated using built-in image_gen edit mode and the finished storehouse reference. Full prompts are in prompts.json. Original sources, full-canvas nearest-neighbor exports, and 8x previews are preserved.

Stages: ground stakes/string, stone foundation, frame, plank floor, half-shingled roof. Geometry and ground anchors drift across frames; foundation thickness and frame depth vary. Colored fringe pixels and excess shading require cleanup. Final style and alignment audit remains open. No game integration performed.
