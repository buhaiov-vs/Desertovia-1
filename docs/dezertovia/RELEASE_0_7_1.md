  с автором, зданием, координатами и кнопками одобрения/отказа. Первопричина:
  новый путь создания CivicOrder сохранял заявку без Telegram уведомления.
  Теперь отдельная долговечная очередь15с, включая накопленные заявки.

  только для личных карточек/сводок владельца. Без поиска по нику и UUID из текста.

  расстояние, откат, стены, лечение/данж. Будущая волна не даёт бесплатного HP.

  ранения, ущерб, добычу и историю; повтор безопасен.
