## Боевой опыт XP-01

Вход FightCitizen после реально снятого HP: учитывать отдельно damage melee/bow,
а не оружие в момент завершения, чтобы смена лука не переписала вклад. Новые
nullable счётчики RaidFighter, старый JSON берёт суммарный damage. Завершение
RaidSimulation.Finish под существующим RewardsGranted: максимум10 статXP на
волну, ceil(actualDamage/10), ближний бой70% сила/30% ловкость, лук20%/80%.
Нулевой вклад/AFK/полученный урон без ударов не награждать; ручной override и
отмена не дают нового statXP. Каждый участник делит только свои10XP; обычный
Progression.AddExperience сохраняет предел10/талант30 и перевод в славу, затем
SkillRules.CatchUp. Не давать очки на каждом сетевом повторе. Dungeon уже имеет
свой statXP по outcome, не удваивать; PvP/союзники не источник этого XP.

## Исследования KNOW-01

Вход TechnologyRules: вложить общие ResearchPoints только в ТЕКУЩУЮ выбранную
голосованием технологию. Царь/посадник, нужное исследовательское здание и уже
начатая работа людей обязательны. Одно вложение на технологию: до25% её Cycles,
по5очков за цикл, не больше оставшегося. Сохранить KnowledgeWork (default0) в
существующем TechnologyProgress, отдельного реестра открытий не делать. Повтор
в ту же технологию возвращает состояние без списания. Не добавлять researchHands,
не обходить prereqs/голосование/число людей/требования исследователей, не давать
XP за бюджет. Если work закончен, но crew не хватает, открытие ждёт обычного
исследователя. Если crew уже есть — пометить существующую технологию открытой.
API technologyId + роль под village lock; обычные сохранение/broadcast/DTO.
UI внутри дерева выбранной технологии: цена/эффект/остаток/причины, без HUD.
Рецепты автоматически открываются существующими Baking/Brewing: не второй unlock.

## Два блюда COOK-01

Каша: Grain2+Wood1→1порция в Bakery (Baking, Skill.Baking0),20реальных минут
расхода сил на работу ×0.9. Похлёбка: Food3+Wood1→1порция в Tavern (Brewing,
Skill.Baking0),20минут фактического урона в набеге ×1.05. Это обычные оплаченные
производственные taskциклы/доставка/склад/личная работа, а не мгновенный craft.
Использовать2готовых goods и только имеющееся сырьё, обычные food icons и палитру.

Citizen MealKind/MealUntil/LastMealAt nullable, отдельная additive миграция.
Съесть только из своих рук/рюкзака, осознанная кнопка в инвентаре; нельзя пока
без сознания/на лечении. Одновременно один эффект; нельзя заменить/сложить/продлить,
общий перерыв30минут, длительность20. Не восстанавливает HP/энергию, обычная Food
и узвар сохраняют свой смысл. Продолжительность и cooldown переживают перезапуск.
Не давать старым поселенцам готовые блюда или бонусы. Рабочая цена учитывается
одной функцией для UI и списания; боевой множитель только к реальному удару,
никаких ежетиковых DB/modelcalls. В инвентаре показывать активный эффект и время,
не добавлять постоянную панель. Нет эффекта→старый расчёт бит-в-бит.
