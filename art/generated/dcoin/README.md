# Dcoin

Generated for the owner-approved 0.7.1 plan: front-facing golden pixel coin,
embossed D, transparent background, warm highlights and dark contour.
Original: dcoin-source.png. Runtime: web/public/assets/dcoin.png (48×48, shown
at 24×24). Rebuild with `python scripts/prepare_dcoin.py`; the existing shared
outline style is baked into the PNG, with two source pixels per display pixel.
No runtime filters, dilation or recoloring. No currency amounts or prices change.
