# Construction props — draft batch

Four outputs generated separately using built-in image_gen and both original Kenney sheets as style references. Exact prompts are in prompts.json. Sources, 16x16 nearest-neighbor exports and 8x previews are preserved. The ground tile is opaque as required for terrain; the three props have transparent corners.

Placement outline remains code-drawn, following docs/sprites.md.

Native-size visual audit: survey peg uses too little canvas and needs a tighter framing; signboard hammer is weak at native size; ground footprints and chips disappear into noisy texture and seamless edges are unverified; pallet reads as three boards but needs palette/edge cleanup. These outputs are drafts, not final approved game assets. No game integration performed.
