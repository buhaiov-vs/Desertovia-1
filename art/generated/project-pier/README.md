# Pier pieces — drafts

Pier poles and deck generated individually using built-in image_gen with original Kenney style sheets. Exact prompts are in prompts.json. Sources, 16x16 nearest-neighbor exports and enlarged previews are preserved.

Both exports passed dimension and transparent-corner checks. Native review: two poles read clearly, but ripple rings reduce to blue blocks. Deck source is rectangular despite square request; full-canvas export compresses its width. Three board divisions/nails are weak at native size. Six of sixteen opposite-edge pixel pairs differ, so seamlessness is not accepted. Rework deck proportions, palette and joins, then audit pole/deck alignment. No game integration performed.
