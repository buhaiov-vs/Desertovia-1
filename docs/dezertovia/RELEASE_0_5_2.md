# Дезертовия0.5.2 — кандидат, не выложен

Общий пакет подготовки. Источник: feat/cooperative-update игры и бота.
Версия в настройках берётся из web/package.json. Сервер и живая база не изменены.

- Больница со стройкой и уровнями, отдельными карточками пациентов, лежащими
  персонажами, причиной и сроком лечения. После боя житель может отнести раненого;
  если помощь не пришла за5 минут, придут санитары. Переноска не лечит и не меняет
  вещи. Без здания работает временный лазарет. На карте разнесены до4 видимых
  коек со своим персонажем среди них; полный список доступен в больнице.
- Дуэльные ранения и лечение синхронизируются с батюшкой по числовому Telegram ID.
  Старые тарифы сохранены; повтор запроса использует ту же квитанцию. Бесплатная
  выписка иногда даёт одно временное смешное осложнение. Боевые снадобья отдельно.
- Новый мост строится стадиями с коллективным вкладом. Добыча за закрытым мостом
  заблокирована сервером. Подготовка первого моста доступна с Умом3/Стройкой1;
  сам объём стройки увеличен. Уже завершённые и старые текущие проекты сохраняются.
- Строители получают славу за полезную работу. Добавлены улучшения, износ,
  медленный ремонт и разборка через заявку с окончательным решением царя.
- Склады получили отдельные лимиты ресурсов и улучшения; старые излишки не
  уничтожаются. Общий жилой дом вмещает12/20/28 жителей. Заселение сохраняется,
  браки читаются из батюшки, совместное проживание требует согласия и одобрения.
- Истощение замедляет работу, а упорная работа без отдыха приводит к обмороку.
  Обычная ходьба не замедляется. Энергетик требует квалификации и ингредиентов.
- Батюшка молчит без свежего разговора и реже повторяется; говорит о проверенных
  событиях деревни. Светлая/тёмная тема интерфейса независима от игровой ночи.
- Подключены готовые одинаковые обводки зданий; зомби и скелеты визуально крупнее.
  Лишние постоянные подписи зданий скрыты, действия доступны по нажатию.

Кнопки выхода/удаления города убраны из UI, старые авторские API не удалены.
Новые командир/замок/катаклизмы/кланы/реальный обмен валют не добавлены. Существующие
набеги и данжи сохранены. Прогресс не сбрасывался. Внешний больничный мост включается
отдельно после совместной установки проверенных версий, по умолчанию выключен.

Числа — стартовый баланс, не доказательство календарного срока стройки. Полные
ограничения и проверки: IMPLEMENTATION_LOG.md и BALANCE_PROPOSAL.md.
