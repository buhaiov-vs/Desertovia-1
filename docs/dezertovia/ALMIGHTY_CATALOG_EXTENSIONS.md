# Новые враги и предметы — D-057

Владелец спросил, надо ли отдельно прописывать их ИИ. Ответ: игровые каталоги —
единый источник. Snapshot автоматически содержит EnemyCatalog, ResourceKind /
ResourceNames и рецепты GameCatalog. Применимые варианты нападения строятся из
Undead&&!DungeonOnly; Coordinated включает серверные направления. Модель выбирает
только server-issued option ID. При согласии каталог/условия проверяются заново.

Новый враг в существующем бое: добавить тип/спрайт/переводы/EnemyDefinition,
характеристики и признаки допуска. Отдельный prompt/таблица врагов ИИ не нужны.
Новое оружие: обычный resource + recipe + Armory rules. Это попадает в сводку;
модель не получает возможности изобретать отсутствующие эффекты.
Новая механика (полёт, осада, яд) требует сначала серверных правил и допустимого
адаптера/параметров. Описание «летает» не делает наземный renderer летающим.

Большие каталоги передаются ограниченной релевантной сводкой, а не каждым
пикселем/всеми сущностями. Полное состояние принадлежит серверу. Враги знают
лишь разрешённые им цели; общая осведомлённость директора не право обойти реку.
