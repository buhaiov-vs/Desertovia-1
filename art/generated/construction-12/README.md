# Tavern construction stages

Five 64x64 drafts generated with built-in image_gen edit mode using the finished tavern reference. Full prompts in prompts.json; sources, full-canvas nearest-neighbor exports and 8x previews preserved.

Stages: ground markers, foundation, frame, half-height log walls, half-thatched roof. Wall-stage masonry is too tall and geometry differs across stages. Ground markers have fringe artifacts; final palette and alignment audit remains open. No game integration.
