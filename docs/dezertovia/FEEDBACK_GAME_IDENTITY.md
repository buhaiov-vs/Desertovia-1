# D-072 — игровой код автора отзыва батюшке

16.10.2026, feat/feedback-game-identity. Только репозиторий, без установки.
Добавление к ближайшим исправлениям, без повышения версии за отдельный коммит.
Проверенный кандидат0.7.1/573af93 и его receipt остаются отдельным состоянием;
данная новая ветка требует собственных проверок и согласованной game/bot установки.

POST /api/feedback/identity: прежний доверенный bridge-заголовок, без доступа
по обычной cookie. Вход — TelegramUserId реального отправителя у бота.
Ответ: linked, AccountId (код из настроек игры), CitizenId при наличии,
имя и город. Поиск только по ExternalLogins.Provider=telegram и точному ID;
одинаковые имена, смена @ника и посторонний UUID в тексте не влияют.

Только AsNoTracking/SELECT. Нет создания аккаунтов, присоединения к городу,
синхронизации больницы, settlement, изменения прогресса или выдачи имущества.
Учитывается PrimaryVillage; царь без Citizen получает собственный код аккаунта.
Без привязки — linked=false, без угадывания. Ответ no-store, без кошельков,
характеристик/навыков/секретов. Миграции EF не нужны.

В парной bot-ветке сохраняется исходный отзыв до HTTP-запроса, таймаут2с.
Снимок Telegram ID/AccountId/CitizenId показывается только хозяину в карточках,
сводке и прежнем приватном read-only отчёте. Новые технические поля не отправляются
модели сводки. Сбой игры не теряет отзыв, старое авторство по нику не переписывается.
