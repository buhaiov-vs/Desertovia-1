# 0.5.3 — исправления после отзывов игроков

D-049: владелец разрешил реализацию и выкладку после проверок. База0.5.2,
план REGRESSION_FIX_PLAN_0_5_2.md. Состояние: код готов, итоговая проверка идёт,
сервер пока не обновлён. Фактический выпуск фиксируется ниже отдельной записью.

## Изменения

- Выбранный объект временно подавляет чат/тосты: видно название, закрытие и действия;
  черновик/история/непрочитанные и режимы сохраняются.
- Свёрнутый чат — прозрачный контейнер по размеру кнопки; фон тёмной темы не
  возвращается, пустая область не перехватывает нажатия на карту.
- Визуальная проверка дополнительно обнаружила сжатую личную шкалу энергии
  и светлый фон статуса с бледным текстом в тёмной теме. Исправлены flex-размер
  шкалы и контраст статуса, без изменения чисел энергии.
- Свой профиль подписан явно; супруг, жильё и состояния больше не повторяются
  в строках опыта. Уровни/опыт/брак не меняются.
- Названия зданий привязаны к крыше, стройплощадки — к видимой стадии, с постоянным
  экранным отступом. Световой ореол не участвует в расчёте.
- Полезный объём работ резервируется для обычных строек/улучшений/разборки и
  работ общего проекта: строительство, разметка, доставка. Занятый объём нельзя
  повторно занять новым действием. Отказ происходит до расхода энергии.
- Резерв — nullable-поле оплаченного цикла, отдельный идентификатор проекта;
  additive-миграция ConstructionWorkReservations. Старые циклы заканчиваются
  по прежним правилам; пока они не завершены, новые не занимают ту же работу.
  Пауза лечения сохраняет резерв, завершение/отмена освобождает его.
- Блокировка деревни на транзакции PostgreSQL защищает параллельные экземпляры
  API и settlement. Тесты включают отдельные экземпляры GameService.
- Карточки поручений показывают серверную стоимость энергии с погодой и
  осложнениями. Усталость определяется при старте относительно цены; восстановление
  сил не ускоряет уже начатый цикл. Подсказки приведены в соответствие.
- Номер в настройках берётся из package.json0.5.3. Необязательная выгрузка
  диагностических артефактов CI не делает успешные тесты ошибкой при квоте GitHub.

Время добычи/стройки, расход энергии, опыт, очередь1+1 и роли не упрощались.
Реальные свечи/больничные тарифы/Telegram-привязки/другие игры не менялись.

- Production frontend build: PASS.
- Domain:329 PASS на итоговом исходнике.

## Выпуск и сохранность

После успешных проверок: точный SHA, PostgreSQL backup, приватный снимок профилей,
подготовка образа без остановки старой игры, установка с миграцией, health/auth,
версия клиента и сохранность навыков/опыта/профилей. Бота не переустанавливать.
При проблеме откатывать код совместимо с additive-полями; не восстанавливать
старую БД поверх новых действий игроков и не удалять оплаченные циклы.
