# Farming beds — draft batch

Six 16x16 terrain tiles: dry and wet left, middle, right. Built-in image_gen generated the dry tiles using the original Kenney sheets as style references and edited each dry source into its wet counterpart. Exact prompts are in prompts.json. Sources and 8x nearest-neighbor previews are preserved with the native exports.

Dimension checks passed for all six exports. Terrain is opaque. Native-size review found mismatched grass colors, furrow heights and widths across neighboring pieces. Water glints disappear at native size. The generator retained gradients instead of flat palette colors. These tiles do not pass seamlessness or final style acceptance yet; regeneration/alignment and palette correction remain required. No game integration performed.
