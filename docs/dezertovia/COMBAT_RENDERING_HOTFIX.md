# Бой, больница и верхняя панель · 16.10.2026

В PR46 / fix/civic-request-capacity, вместе с очередью D-074 и русскими
причинами недоступного улучшения. Не установлен; Live0.7.1/e5de51e прежний.
Номер не повышен. Никаких миграций, изменений баланса или прогресса игроков.

## Причины рывков, подтверждённые кодом

- Каждый новый damage здания входил в общий ключ всей застройки. При очередном
  ударе уничтожались и заново создавались ВСЕ изображения зданий, подписи и
  ночные источники света. Теперь damage — отдельные обновляемые накладки:
  исходные здания/свет сохраняются, накладки удаляются при ремонте/сносе.
- Полоски здоровья и выделение Graphics очищались и заново строились каждый
  кадр даже без изменений. Теперь перестраиваются при смене здоровья/выделения.
- Кадровый цикл каждого жителя заново собирал все списки бойцов. Теперь индекс
  бойцов собирается один раз на кадр. Нет повторного civilian pathfinding к
  устаревшей точке царя, пока он движется по авторитетным данным боя.
- Каждый снимок заново размывал и загружал ту же текстуру explored. Повтор
  неизменной строки больше не вызывает перерисовку; обычный обзор тумана остаётся.
- Враги догоняли секундный снимок за200мс и затем стояли. Интерполяция теперь
  распределена по секунде, большие переносы остаются мгновенными. Попадание
  кликом проверяется по нарисованному месту, не по следующей серверной позиции.

Это устранение найденных источников работы, не доказательство точной причины
всех фризов и не обещание FPS телефона. Для оценки оставшейся нагрузки нужен
повтор реального боя после отдельно разрешённой установки; пока его не было.
Серверный расчёт, секунды tick, маршруты/ворота/урон/сила противников не менялись.

## Управление

Выбор врага теперь отправляет одну команду intercept: персонаж подходит и бьёт
автоматически. При обновлении здоровья/состояния повторная команда не уходит.
Четыре обязательные кнопки убраны; краткая карточка даёт здоровье, результат
выбора цели и понятную ошибку с повтором при отказе. Закрытие не отменяет атаку.
Царь вступает Воеводой. Для обычного жителя остаётся дело охраны и его серверные
проверки; работа/лечение не отменяются молча. Новая всеобщая самооборона не
включена и отдельно записана в NEXT_TODO. Режим hold сохранён в API для
совместимости, обычный выбор цели всегда intercept.

## Карта и HUD

Если больница готова, госпитализированные не лежат рядом со зданием: на карте
остаётся счётчик, пациентов открывают в существующей карточке больницы.
Без построенной больницы полевой лазарет по-прежнему показывает кровати/ники/
причины. Раненые, ещё ожидающие переноски, остаются на поле. После выписки
обычный персонаж снова видим. Сроки/госпитализация/переноска не менялись.

Валюты включены в общую верхнюю панель. На телефоне шесть компактных ресурсов
в первой строке, энергия/мораль, погода и личные Dcoin/тестовые свечи во второй.
Названия валют есть в подсказке/доступной подписи и полном кошельке; тестовые
свечи остаются явно помечены. Полные ресурсы доступны в прежних подсказках,
в узкой ячейке длинное число не растягивает сетку. Покупки, обновление баланса,
полный кошелёк и источники валют прежние. Никаких реальных свечей не подключали.
