# Onion dome props — drafts

Gold and blue-with-stars dome variants on short white drums, with Orthodox crosses. Built-in image_gen, separate generations using Tiny Town and Tiny Farm references. Exact prompts in prompts.json. Source images, 16x32 exports and 8x previews preserved. Export fits visible bounds proportionally within one transparent pixel using nearest-neighbor sampling.

Dimensions and transparent top-left corners verified. Major shapes present, but sources are too detailed and shaded. Cross occupies a large share of each sprite; bars and stars lose definition at native size. Gold and blue geometry differs and must be aligned if used interchangeably. Edge artifacts, palette simplification and attachment placement remain open. Parent Onion dome catalog row stays pending final review; separate variants tracked in scenery-variants-catalog.json. No game integration.
