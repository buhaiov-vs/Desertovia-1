# Resource samples, batch 2

Six additional rows from docs/sprites.md: Stone, Food, Coal, Iron ore, Iron ingot, and Planks.

Each item has a transparent 16×16 PNG, an 8× nearest-neighbor preview, and its untouched generated source. Open index.html to compare the small exports. Full prompts are in prompts.json; generation used built-in image_gen with Tiny Town and Tiny Farm as references.

Exports use the same transparent-bound trimming and nearest-neighbor resampling as the first samples. These remain style trials, with more shading and detail than the reference sheets, and have not been integrated into the game. Food details become abstract at 16×16.
