# Grass scenery drafts

Three 16x16 opaque terrain exports: plain meadow, two tufts, and three flowers. Built-in image_gen, one generation per asset using Tiny Town and Tiny Farm style references. Exact prompts in prompts.json; original sources and 8x previews preserved. Export uses full-canvas nearest-neighbor sampling.

Dimensions and opaque corners verified. These are drafts: source texture violates the flat two-green palette and strict logical pixel grid. Native exports contain 34, 36 and 48 colors respectively. Opposite edge mismatch counts (horizontal/vertical) are 16/15, 14/15 and 15/12. Seamless acceptance has therefore not passed. Tiny details lose shape at native resolution; simplify and align the pixel grid before integration. No game integration performed.
