## Блокировка двери и нулевой прогресс — подтверждённый инцидент

Read-only аудит38791449432 подтвердил просроченный hang-door с резервом1,
без травмы/лечения/обморока. Сотни ошибок settlement. Исключение:
`JobProgress.ConstructionSite__synthesizedOrdinal` / `SiteHand...`: внутренний
ключ после сохранения оказался изменённым. В FinishAccounting повторный Save
того же EF-графа после удаления законченной стройки пытался пересохранить
перенумерованные вложенные Progress/Hands. Транзакция откатывалась.

Кроме того, раньше одна транзакция содержала несколько граждан, а события
выдавались ДО commit: поздняя ошибка откатывала чужую работу, но отчёт об
успехе уже попадал в чат. Это объясняет повтор «Построено: Хижина».

Исправление: контекст считает успешные сохранения; FinishAccounting сохраняет
несохранённое действие один раз, затем очищает уже сохранённый tracking и
добавляет ledger в той же транзакции. Завершение каждого гражданина отдельной
транзакцией, сбой одного не откатывает других; уведомления после commit.
Никакого принудительного удаления резерва/выдачи ресурсов. Старые просроченные
циклы повторно завершит обычный worker после будущей установки.

## Ошибка ИИ

Приватный read-only аудит38789610769:4анализа,2успешных и2общих отказа;
снимки9970–12465символов, ниже36К. За4часа общие логи провайдеров содержали
6ошибок авторизации и29прочих отказов. Это НЕ6разных ключей. Старый код
проглатывал исключения/неправильный JSON вnull, точную историческую причину
именно двух отказов восстановить нельзя. Аудит не отправлял запросов модели,
сообщений и не менял сервер.

Найдены и исправлены два дефекта: клиент игры ждал15с при допустимых18–22с
модели; общий LLM.clean обрезал структурированный JSON до1500символов.
Теперь auth сохраняет15с, director получает50с; только директор получает
response_limit4096, обычный чат остаётся1500. JSON разбирается до фильтра
внутреннего часового ориентира, фильтруются только строковые поля ответа.
Бот возвращает безопасные errorCode, журнал игры различаетJSON/поля/запрещённый
инструмент/таймаут/провайдер/общийбюджет/бюджетдиректора. Ошибка ничего не
применяет. Сырые ответы/ключи/чат/исключения провайдера в журнал не выдаются.
Чужие ключи и доступность провайдеров этим не исправляются.
